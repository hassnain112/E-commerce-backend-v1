# E-commerce-backend-v1
RESTful e-commerce backend using Spring Boot, JPA, Hibernate, and MySQL.

## Features

- User CRUD
- Product CRUD
- Category CRUD
- Order Management
- Order Items
- DTOs
- JPA Relationships
- Validation
- Global Exception Handling

## Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
